# Security

For a potential data-loss or security issue, use GitHub's private vulnerability reporting for this repository when available. Otherwise open an issue containing only a minimal synthetic reproduction; do not include private file contents, credentials, or personal paths.

Please include the app version, Windows version, filesystem type, deletion mode, and a reproduction using disposable files. Stop using the affected operation while investigating. The first release is pre-1.0 and receives fixes on the main branch.
